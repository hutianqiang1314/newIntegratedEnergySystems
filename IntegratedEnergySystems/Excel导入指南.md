# Excel数据收集模板导入指南 - 解决中文乱码问题

## 🚨 中文乱码问题解决方案

### 方法一：使用UTF-8 BOM格式（推荐）

新的CSV文件 `data_collection_template_utf8.csv` 已包含UTF-8 BOM标记，应该能在Excel中正确显示中文。

**导入步骤**：
1. 打开Excel
2. 点击"数据" → "获取数据" → "来自文本/CSV"
3. 选择 `data_collection_template_utf8.csv`
4. 在预览窗口中检查中文是否显示正常
5. 如果正常，点击"加载"

### 方法二：手动设置编码格式

如果方法一仍有问题：
1. 在Excel导入对话框中
2. 找到"文件来源"或"编码"选项
3. 依次尝试以下编码：
   - **UTF-8**（首选）
   - **中文(简体,GB2312)**
   - **中文(简体,GBK)**
   - **Unicode (UTF-16)**

### 方法三：记事本转换法

1. **用记事本打开CSV文件**
2. **另存为**：
   - 编码选择：**UTF-8** 或 **ANSI**
   - 保存为新文件名：`template_converted.csv`
3. **用Excel打开转换后的文件**

### 方法四：LibreOffice Calc导入法

如果Excel持续有编码问题：
1. 下载免费的LibreOffice Calc
2. 打开CSV文件时会弹出导入对话框
3. 设置字符编码为UTF-8
4. 导入后另存为Excel格式

### 方法五：直接在Excel中创建（最可靠）

如果所有导入方法都失败，建议直接在Excel中手动创建模板：

## Excel公式验证

### 1. 车辆比例检查
```excel
=IF(SUM(ICV_ratio,EV_ratio,HV_ratio)=1,"✓ 比例正确","✗ 比例错误")
```

### 2. 储能容量检查
```excel
=IF(AND(E_storage_min<E_storage_0,E_storage_0<E_storage_max),"✓ 容量约束满足","✗ 容量约束违反")
```

### 3. 时序数据长度检查
```excel
=IF(LEN(时序数据单元格)-LEN(SUBSTITUTE(时序数据单元格,",",""))=23,"✓ 24小时数据完整","✗ 数据点不足")
```

### 4. 必需参数完成度
```excel
=CONCATENATE("完成度: ",ROUND(COUNTIF(实际值列,"<>")/COUNTIF(必需列,"是")*100,1),"%")
```

### 常见乱码现象
- **问题**：中文显示为 `ç§»æ°` 类似符号
- **原因**：编码不匹配
- **解决**：使用UTF-8编码

- **问题**：中文显示为 `???` 或空格
- **原因**：字符集不支持
- **解决**：确保系统支持中文字符集
